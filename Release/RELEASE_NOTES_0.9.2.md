# IwashiScope 0.9.2

測定履歴の操作性と英語表示を改善した更新です。

- 測定履歴カードの複数選択とドラッグによる並べ替えを改善
- 先頭、末尾、折り返し位置のドロップ判定とハイライト表示を修正
- ドラッグ後や測定中の終了でアプリが応答しなくなる問題を修正
- 英語ローカライズを追加
- 測定履歴カード、演色評価、TM-30表示のレイアウトを調整
- キャリブレーション案内に所要時間の目安（8〜10秒）を追加
- Intel MacとAppleシリコンMacに対応するUniversal Binary
- macOS 14.6以降に対応

アプリはDeveloper IDで署名し、Appleの公証を完了しています。

このReleaseには、配布バイナリと正確に対応する完全なソース一式を含めています。ライセンス、第三者著作物、ArgyllCMSからの変更内容は、ソースZIP内の `LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`、`ARGYLL_CHANGES.md`を参照してください。
